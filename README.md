# ReduceAll

Progetto personale · Prodotti

Web app per compressione, conversione e strumenti di elaborazione dei documenti.

## Esigenza

Ridurre l’attrito nelle operazioni quotidiane sui file.

## Contributo

Ho organizzato strumenti diversi in un’unica esperienza web.

## Stack

React, TypeScript, PWA, Python.

## Una scelta da raccontare

Ogni operazione ha un flusso dedicato e un risultato scaricabile.
